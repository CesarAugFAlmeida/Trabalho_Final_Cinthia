# Trabalho_Final_Cinthia

Este repositório tem como objetivo organizar os arquivos para o trabalho final da matéria Linguagem de Programação Orientada a Objetos.

O tema que foi proposto ao trabalho é de se fazer um sistema que ajude em alguma situação do mundo real, e portanto, este sistema trata-se de um:

# Sistema de Gestão de um Centro de Reabilitação de Animais Selvagens

O sistema visa gerenciar este centro com uma classe abstrata "AnimalSelvagem" que é ramificada em outras classes filhas para os diferentes animais, cada uma com atributos e métodos ou herdados, ou criados dentro das classes filhas.

A interface gráfica deve ser feita na IDE Apache NetBeans!
